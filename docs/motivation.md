# Motivation
会社活動には, 経営方針に沿って行われる事業や組織作り以外にも, 多くの自発的な活動が存在しています. 
これらの個人活動は, たとえ会社方針のために始まったものでなくとも, 結果として社員の成長やチームの強化につながり, 会社の未来を形作っています.
しかし, こうした個人活動や暗黙的な目標を会社が取り込むには, とてつもない労力が必要とされてきました. そのため, 本来であれば会社の成長に繋がるはずのそれらが, 十分に見える化されず, まだまだ潜在的な力として眠ってしまっているのです.
これを解決するには, 個人の目標や活動を聞き出し, 会社目標と重なる点を探して, 挑戦する機会提供までの包括的な支援が必要です. 
そこで今回, これらの問題を解決する方法として, 既存の販売計画業務を応用したソリューション「coco-match」の開発を行いました.
